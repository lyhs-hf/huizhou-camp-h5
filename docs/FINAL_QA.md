## 体验变化

- `App.tsx` / `Station.tsx`：核心六幕退出统一 Station 卡片、固定页码、常驻知识入口与页脚。边缘导航保留，继续入口在视觉回报后出现；暖光、墨色、木桌、树影、云、窗与纸连接空间。
- `Macaque.tsx`：删除固定坐标到位、调焦 slider、观察 timer 和预设答案。实际手势扫过的可见细节决定札记内容，不宣称追踪眼球；未经过的松枝不写入记录。
- `Mountain.tsx`：删除 height / slider / 自动推进。一次上推推动近景与松枝，惯性穿云后展开群峰；云清开后至少三秒不出现可见文字、按钮、进度或页码。
- `Ink.tsx`：转动发现凸纹，沿实际指迹留金；无 1/3 与收笔任务。成品静观 2.6 秒；返回保留相同笔迹，不补齐未描部分。
- `NewYear.tsx`：保留入模、三次敲击、脱模与点朱；删除祝愿选择题。展开红纸触发一笔“春”，桌面到天井与年宴连续推进，不声称用户写成原创楹联。
- `Lantern.tsx` / `Parallel.tsx`：同一鱼灯轮廓从灯骨、纸面、添色到夜巷，点亮后先观看 4.2 秒；古戏台片刻可选。点茶为一次轻动作，篆香按真实痕迹形成，看山零任务，三者均由用户主动退出，再进入亲子合流。

触觉：纸面 / 年礼；发现：松枝后的猴子；视觉：穿云群峰；情绪：两个世界合拢；价值：Closing 将作品、个人札记与六天路线连接。没有用自评分数或测试数量代替体验判断。
