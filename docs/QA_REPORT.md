## 性能与真实性

23 张 WebP 总计 3,080,242 bytes，最大单张 266,412 bytes，Hero 224,174 bytes。当前幕才挂载，避免首屏加载所有互动图片。Hero 预加载并等待最短序幕时间；代码 JS gzip 约 89.4KB、CSS gzip 约 7.5KB。山景采用 transform/opacity；模糊照片与清晰照片交叉淡入，没有逐帧动画 CSS blur。没有持续运行的粒子动画或第三方字体请求。

全局状态为内存，电话号码未进入 reducer、Analytics、localStorage/sessionStorage。自动测试监听到的联系人网络传送为零。Demo adapter 不做网络请求。

官方标志与字体授权；正式营期、费用和实际行程；短尾猴与手作图像的文化/动物细节；真实留资接口、CRM 和隐私条款；正式分析服务；iOS/Android 微信输入法、安全区、触摸与长按保存。没有高质量可用音频，本版按允许的静音方案交付，没有未授权音效。

## 最值得下一轮打磨的三处

1. 用同一拍摄或同一母版鱼灯统一骨架、未点亮、点亮三个状态的轮廓与纹样。
2. 对黄山五个透明层做同一镜头的光色与透视校正，进一步减少近景松枝的合成感。
3. 在取得授权后接入正式中文品牌字体，对标题标点、字距与行旅卷微排版做最后校准。
